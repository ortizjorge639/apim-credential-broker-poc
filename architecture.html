JWT gate does not force per-user tokens

Validating the caller JWT (aud, issuer, oid) proves who is calling APIM. It still maps every allowed caller to the same stored connection c2. Per-user backend tokens need a per-caller authorization-id bound to a user identity.
Also: the 401 error body leaks token-validation detail. Trim it for production.
