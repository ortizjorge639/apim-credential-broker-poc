# R1 – Credential Manager broker (managed identity) — PASS (2026-10-03)
Steps (all via az CLI / ARM 2022-08-01):
1. GitHub OAuth app `apim-cm-poc` (callback https://authorization-manager.consent.azure-apim.net/redirect/apim/<apim-name>, scope set on provider: read:user). Secret kept in session files/secrets (not here).
2. PUT .../authorizationProviders/github (identityProvider=github, authorizationCode grant).
3. PUT .../authorizations/conn1; POST getLoginLinks (needs postLoginRedirectUrl); user consents in browser -> status Connected.
4. API `ghproxy` (/gh, backend https://api.github.com), op GET /user, policy: get-authorization-context(identity-type=managed) -> set-header Bearer AccessToken (+User-Agent).
5. Enable APIM system identity; PUT accessPolicies/apimmsi {objectId, tenantId}.
Result: curl https://<apim>.azure-api.net/gh/user (no creds) -> 200 with GitHub profile.
Finding: BEFORE the access policy for the APIM managed identity existed, the call returned HTTP 500 (Connected status alone is not enough). Consumption tier, no caching.
